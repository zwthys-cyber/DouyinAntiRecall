抖音推送缓存检查 · WQ Files 自定义检查器

用途：只读检查抖音 41.2.0 SDK 使用的三个已确认缓存键。不是免签工具，也不是推送修复补丁。

1. 将 ZIP 分享给 WQ Files 安装检查器；需使用支持 Custom Inspectors 的 WQ Files 版本。
2. 先关闭抖音，再在 WQ Files 打开应用数据中的抖音。
3. 进入 Library/Preferences，长按 com.ss.iphone.ugc.Aweme.plist → Open As（打开方式）→ Custom Inspector（自定义检查器），选择“抖音推送缓存检查”。这是预期的标准偏好设置位置，文件不存在时不要新建。
4. 将检查器的结果分享为文本，不要分享原始 plist 或整个应用数据。

不显示令牌内容，不读取其他键，不打印原始文件，不写回，不发起网络请求。结果中的“存在”不表示绑定或投递成功；磁盘偏好设置不一定与运行中的内存状态同步，未找到也不能证明没有令牌。

WQ Files 本身必须已获得有效 App Group，且能访问抖音的数据目录；本 ZIP 不能补齐其签名授权。iOS 27.0.1 无法访问应用安装包目录不影响本工具只读取应用数据的用途，实际访问仍取决于设备。
