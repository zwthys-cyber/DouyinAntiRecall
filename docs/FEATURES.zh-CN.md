# v0.2.6 设置、属地、音频和原图

安装方式沿用已有独立 dylib：退出抖音，在 TrollFools 移除旧版，再注入新版。目标仍为抖音 41.2.0（412021）、iOS 17.0 + TrollStore。

## 设置入口

进入抖音自己的“设置”，顶部新增“抖音增强”。插件页包含独立开关：

- 消息防撤回：默认开。
- 显示已撤回标记：默认开，可单独隐藏灰色标签。
- 显示 IP 属地：默认关。
- 视频音频入库：默认关。
- 评论区发送库内音频：默认关。
- 无水印保存图文：默认关。
- 评论图片无水印：默认关。
- 评论时长跟随手动录音：默认开，音频文件不裁剪。

音频库也可以直接从这个页面打开。

## IP 属地

在视频原有时间标签旁显示省市信息。国内城市码使用参考项目的离线映射，缺少城市码时使用抖音提供的 ipAttribution。国外也优先使用平台已提供的属地信息；没有接入额外位置查询服务。开关变化后可以滑到下一条视频查看。

这里的“IP”指 IP 属地，不是网络 IP 地址，也不修改账号的属地。

## 音频入库和评论发送

1. 开启“视频音频入库”，长按视频选择“音频入库”，或者从音频库右上角导入自己的音频文件。
2. 每条音频右侧有试听和“发送”按钮；点文件仍可打开试听、用于下一条评论语音和删除菜单。
3. 开启“评论区发送库内音频”后，点文件右侧“发送”，等待加载状态结束。发送按钮先准备音频，再按下一步完成评论发送。
4. 回到评论区，按希望显示/提交的评论时长，使用抖音原有语音按钮手动录音后松开，发送已选择的音频。默认保留手动录音时长字段，音频文件仍是原来长度，不裁剪。
5. 每次准备只替换下一次评论语音，5 分钟内有效。取消录音不消耗准备状态；关闭开关、手动取消或重启应用后不会继续待发。

准备时将完整音频转换为 M4A，不再自动截取前 29.5 秒。默认不把录音器或上传模型的手动时长改成文件时长；关闭“评论时长跟随手动录音”则沿用原音频时长模式。平台可能校验或重新计算时长，真实发送和接收端显示以设备验收为准。音频文件保存在抖音沙盒 `Documents/DouyinAudioLibrary/`，单个导入/下载文件不超过 50 MB。音频库界面支持取消待发送文件；删除当前已选文件也会取消待发。下载入库根据 MIME 类型和原始链接保留音频扩展名，避免临时文件扩展名造成试听失败。

发送通过已确认的评论录音控制器、评论音频上传管理器和 Swift 评论上传器的 ObjC 入口接入。未使用全局文件移动或私信发送拦截。若账号或应用界面没有原生评论语音按钮，本版不会替账号开通此功能。

## 无水印保存图片

开启开关后，长按图文视频可选择“保存当前原图”；多图时还有“保存整组原图”。优先下载 AWEImageAlbumImageModel.watermarkFreeUrlList，缺失时使用展示用原图 urlList，不使用加水印的下载接口。保存时由系统请求添加相册权限。

保存图片会读取 EXIF DateTimeOriginal（原始拍摄日期），缺失时补读 XMP exif:DateTimeOriginal、photoshop:DateCreated 和 IPTC DateCreated/TimeCreated，并设置系统相册中的照片时间。有 OffsetTimeOriginal 时按该时区解释，保留有效的秒小数；没有时区时按设备本地时区解释。兼容 JPEG 转换保留拍摄日期字段，并沿用同一相册时间。每张图片独立处理，完成提示分别显示实际保存、识别到日期和成功按日期归档的数量。识别数量独立于相册写入结果。

如果下载原图没有有效拍摄日期，使用系统默认保存时间。不会用作品发布时间、文件修改时间或数字化时间冒充拍摄时间。元数据可能由作者编辑，本功能读取已有信息，不能证明实际拍摄时刻；也不会修改此前已保存的照片。

这里下载服务端提供的原图；图片本身已经绘制在像素中的水印不会被抹除。不被相册接受的图片格式会尝试按原分辨率转成高质量 JPEG 保存。当前版本不导出实况视频部分，也不包含无水印视频下载。

## 验证边界

编译及测试全部由 GitHub Actions 运行，包括开关持久化/回退、原有防撤回回归、设置模型入口、两种长按菜单不重复、IP 标签恢复、原图链接优先级、真实音频转换和一次性替换。界面测试使用观测到的 API 的模拟对象。

真实抖音的设置入口显示、具体账号的评论语音权限、音频上传完成及接收端播放、图集 CDN 内容和写入真实相册，还需要设备验收。模拟器不发送评论，也不访问用户账号。

额外处理：准备音频后，只允许替换此后产生的新评论录音；同一个已替换文件的后续上传不会消耗下一次选择。导入、下载和转换在后台进行，取消或关闭开关后完成的转换不会重新进入待发状态。

## 保存失败提示与备用地址

每张图按顺序尝试 watermarkFreeUrlList 的地址，之后尝试展示原图 urlList；过滤无效链接并去重。没有地址的图片也计入总张数。写入相册时根据实际文件内容设置格式标识和文件名，格式不被接受时转换 JPEG 后再试，保留已识别日期。

保存不完整时弹窗显示下载 HTTP 状态、网络/文件读取/图片解码失败或相册写入错误码，不再静默只显示 0 张。此前真机失败的具体原因尚未取得错误码，需要用新版在同一条图文复测确认。备用地址也不可用时无法保存。

## 评论图片无水印

开启“评论图片无水印”，在评论图片的原生界面保存，downloadUrl 会改用同一模型的 originUrl。原有图文保存开关继续独立控制作品图集。此开关只改变原生下载地址，不新增评论保存权限，不导出评论实况视频部分；原图地址缺失会提示并停止回退到加水印地址，像素本身已有水印无法移除。

日期补读不会让已经移除元数据的图片产生真实拍摄日期。检查过本版本静态图片模型，未发现可直接当作真实拍摄时间的字段；不会拿作品发布时间代替。

## 登录诊断入口

启动后，屏幕右下角出现“诊断 v0.2.6”，不要求先发生登录错误。点击查看并复制诊断，再将诊断文字反馈；也可从“抖音增强 → 诊断 → 查看登录诊断”进入。关闭诊断窗口不影响原登录提示；“收起入口”隐藏浮动按钮，下一次记录错误时重新显示。报告显示加载版本、宿主匹配状态和 4 个观察点的安装数量；宿主升级弹窗本身也会被观察，不读取其中的标题、正文或账户内容。

显示的账户错误码与进入的处理路径分别记录，不将进入 1049 处理路径当作已经确认返回 1049。只记录 NSError 的错误域和错误码，未提供 NSError 时明确标注未知。保留最新 16 条，重启清空，不写入磁盘，不抓取登录请求或响应内容。签名字段读取仅用于区分配置状态，不表示证书有效或服务器接受。

本版原样转发登录、1049、强制更新和升级弹窗的参数及原回调；真实登录兼容问题尚未解决，需要先取得设备上的实际诊断结果。

入口使用独立的非 key 窗口，位于应用弹窗层上方；按钮以外的触摸穿透，不接管键盘焦点。只读入口在构建号不匹配时仍显示，其余功能 hook 的版本校验保持严格。


## v0.2.12 音频助手界面与文件管理

将参考音频助手的管理流程接入当前 UIKit 页面：搜索、文件夹创建与分层浏览、导入到当前文件夹、文件/文件夹重命名、系统分享、多选批量删除、滑动操作、文件数量/大小汇总与异步时长显示。保留每行独立的试听/发送按钮、准备中的加载状态和取消待发送操作。文件夹显示在音频之前；删除有确认，不启用整行滑动直接删除。库根目录仍是 `Documents/DouyinAudioLibrary`，已有音频无需迁移。

目录管理拒绝路径跳转、越界符号链接及内部 `Prepared` 目录。重命名保留音频扩展名；删除或重命名正在准备的文件或父文件夹会取消对应待发状态。时长扫描异步执行，编辑多选期间不刷新行以免清空选择。分享使用系统面板发送所选原文件，不声称分享操作会自动转换编码。

本次合并上文时长毫秒修正。界面采用本项目的原生导航栏、分组列表、安全区域和系统配色适配参考操作，不含私信发送、变声效果或全局文件移动拦截；评论实际发布仍需设备验收。云端编译与音频助手回归待确认。
