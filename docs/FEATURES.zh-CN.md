# v0.2.0 设置、属地、音频和原图

安装方式沿用已有独立 dylib：退出抖音，在 TrollFools 移除旧版，再注入新版。目标仍为抖音 41.2.0（412021）、iOS 17.0 + TrollStore。

## 设置入口

进入抖音自己的“设置”，顶部新增“抖音增强”。插件页包含独立开关：

- 消息防撤回：默认开。
- 显示已撤回标记：默认开，可单独隐藏灰色标签。
- 显示 IP 属地：默认关。
- 视频音频入库：默认关。
- 评论区发送库内音频：默认关。
- 无水印保存图片：默认关。

音频库也可以直接从这个页面打开。

## IP 属地

在视频原有时间标签旁显示省市信息。国内城市码使用参考项目的离线映射，缺少城市码时使用抖音提供的 ipAttribution。国外也优先使用平台已提供的属地信息；没有接入额外位置查询服务。开关变化后可以滑到下一条视频查看。

这里的“IP”指 IP 属地，不是网络 IP 地址，也不修改账号的属地。

## 音频入库和评论发送

1. 开启“视频音频入库”，长按视频选择“音频入库”，或者从音频库右上角导入自己的音频文件。
2. 在音频库点文件可以试听、删除，或选择“用于下一条评论语音”。
3. 开启“评论区发送库内音频”后选择文件，等待准备完成。
4. 回到评论区，使用抖音原有语音按钮录制约 1 秒再松开，发送已选择的音频。
5. 每次准备只替换下一次评论语音，5 分钟内有效。取消录音不消耗准备状态；关闭开关、手动取消或重启应用后不会继续待发。

为了沿用评论语音的长度，准备时最多截取前 29.5 秒，转换为 M4A。音频文件保存在抖音沙盒 `Documents/DouyinAudioLibrary/`，单个导入/下载文件不超过 50 MB。音频库界面支持取消待发送文件；删除当前已选文件也会取消待发。下载入库根据 MIME 类型和原始链接保留音频扩展名，避免临时文件扩展名造成试听失败。

发送通过已确认的评论录音控制器、评论音频上传管理器和 Swift 评论上传器的 ObjC 入口接入。未使用全局文件移动或私信发送拦截。若账号或应用界面没有原生评论语音按钮，本版不会替账号开通此功能。

## 无水印保存图片

开启开关后，长按图文视频可选择“保存当前原图”；多图时还有“保存整组原图”。优先下载 AWEImageAlbumImageModel.watermarkFreeUrlList，缺失时使用展示用原图 urlList，不使用加水印的下载接口。保存时由系统请求添加相册权限。

这里下载服务端提供的原图；图片本身已经绘制在像素中的水印不会被抹除。不被相册接受的图片格式会尝试按原分辨率转成高质量 JPEG 保存。当前版本不导出实况视频部分，也不包含无水印视频下载。

## 验证边界

编译及测试全部由 GitHub Actions 运行，包括开关持久化/回退、原有防撤回回归、设置模型入口、两种长按菜单不重复、IP 标签恢复、原图链接优先级、真实音频转换和一次性替换。界面测试使用观测到的 API 的模拟对象。

真实抖音的设置入口显示、具体账号的评论语音权限、音频上传完成及接收端播放、图集 CDN 内容和写入真实相册，还需要设备验收。模拟器不发送评论，也不访问用户账号。

额外处理：准备音频后，只允许替换此后产生的新评论录音；同一个已替换文件的后续上传不会消耗下一次选择。导入、下载和转换在后台进行，取消或关闭开关后完成的转换不会重新进入待发状态。
